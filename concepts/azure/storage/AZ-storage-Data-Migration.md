## Azure Data Migration Options — Key Notes

## 1. Azure Migrate

**Purpose:** Assess and migrate on-premises infrastructure, applications, and data to Azure.

Azure Migrate provides a central hub to manage and track migration.

Key capabilities:
- **Discovery and assessment:** Identify existing infrastructure and evaluate migration readiness.
- **Server migration:** Move servers to Azure.
- **Database migration:** Migrate databases.
- **Web app migration:** Migrate web applications.

**Exam tip:** Assessing an on-premises datacenter and planning its migration to Azure → **Azure Migrate**.

## 2. Azure Data Box

**Purpose:** Transfer very large amounts of data using a physical storage device shipped between your location and Microsoft.

### How It Works

1. Order a Data Box through the Azure portal.
2. Receive the physical device.
3. Copy your data onto the device over your network.
4. Return the device to Microsoft.
5. Microsoft uploads imported data to Azure.

Key facts:
- Up to **80 TB of usable storage**, according to this lesson.
- Supports importing data into Azure and exporting data from Azure.
- Useful for datasets of tens of terabytes or more.
- Ideal when network bandwidth is limited or online transfers would take too long.
- Data is securely erased according to the applicable process after transfer.

### Common Use Cases

- One-time bulk migration to Azure.
- Periodic large data uploads.
- Exporting large datasets for recovery or regulatory requirements.

**Exam tip:** Moving massive datasets when internet bandwidth is limited → **Azure Data Box**.

## 3. Main Differences

| Feature | Azure Migrate | Azure Data Box |
|---|---|---|
| Main purpose | Assess and migrate infrastructure and applications | Transfer large amounts of data physically |
| Method | Migration tools and services | Physical storage device |
| Best for | Servers, databases, web apps, datacenters | Large datasets and limited network bandwidth |
| Key idea | Assess and migrate | Copy, ship, and upload |

## 4. Exam Tips and Takeaways

1. **Azure Migrate** is a central hub for assessment and migration.
2. **Azure Data Box** uses a physical device to transfer data.
3. Choose Data Box when online transfer is too slow or impractical.
4. Data Box supports both import to Azure and export from Azure.
5. Remember the Data Box capacity stated in this lesson: **80 TB usable**.

**Memory trick:** Azure Migrate moves your infrastructure to the cloud; Data Box ships your large datasets to or from Azure.
